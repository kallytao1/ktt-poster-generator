# 快团团素材生成器

## 项目与运行方式

本项目是无需构建的单文件网页。直接用现代浏览器打开项目根目录的 `index.html` 即可本机试用。商品图片和二维码由浏览器本地读取；本项目不包含图片上传服务、账号、后端或草稿同步。

代码检查覆盖文案实时预览、价格优惠计算、商品主图和二维码本地读取与预览，以及“导出 PNG”流程；这表示代码测试覆盖，不代表这些项目已在真实浏览器中实际操作通过。图片比例控件包含商品图区域比例自动识别选项，但尚未实现可用交互。

## 尚未解决的问题与下一步验收

1. 实现图片区域比例和适配方式控件，并验证自动识别会按上传图片选择接近 3:4 或 1:1 的区域；比例设置不得改变 720 × 1280 海报尺寸；二维码始终完整显示。
2. 在桌面浏览器实际操作三种模板、恢复示例、图片选择及卖点／价格编辑，验证输入保留、重置范围、实时预览、错误提示及浏览器本地处理。
3. 实际点击导出，打开下载的 PNG，检查文件名、内容与预览一致，并在文件属性／图像信息中确认 **720 × 1280 像素**。
4. 在真实手机或明确的移动视口检查编辑区上下排列、滚动、图片选择、模板切换及导出按钮可操作。
5. 检查控制台错误；上传前再次核对目标仓库现有内容和文件清单。当前目录没有 Git 仓库元数据，无法提供 Git 变更清单。
